# Bundled 3D Articulated Character Models Attribution

All models in `public/models/` are bundled locally so the Studio works offline without external asset fetches.

| Model File | Source / Author | License | Notes |
| :--- | :--- | :--- | :--- |
| `Knight.glb` | [KayKit: Character Pack - Adventures 1.0](https://kaylousberg.itch.io/kaykit-adventures) by Kay Lousberg | **CC0 1.0** | Articulated knight rig, 15 sub-meshes, 76 skeletal animations, embedded pixel-friendly texture atlas |
| `Fox.glb` | [Khronos glTF Sample Assets (Fox)](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox) | **CC0 1.0** | Low-poly rigged quadruped with `Survey`, `Walk`, `Run` animations & textured fur |
| `RobotExpressive.glb` | [Three.js Examples (RobotExpressive)](https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/RobotExpressive/RobotExpressive.glb) by Tomás Laulhé | **CC0 / MIT** | Articulated robot rig with 14 animations + blendshape morph targets |
| `Soldier.glb` | [Three.js Examples (Soldier)](https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/Soldier.glb) | **MIT** | Articulated sci-fi tactical soldier with `Idle`, `Walk`, `Run`, `TPose` clips & PBR textures |
